## Impact

- API/event/schema contract: Draft management reads require authentication;
  inaccessible cross-owner IDs use canonical missing-resource responses; AI
  chat requires `material_id`; successful admin cross-owner mutations append
  `admin.override`. The approved breaking material-file change removes
  `file_path` from material responses and adds
  `GET /materials/{material_id}/download`.
- Migration/data: New single head `ca82f9a51d44` adds two nullable owner UUIDs,
  two exact named `RESTRICT` FKs, and nine non-unique B-tree indexes. It performs
  no backfill/DML. Downgrade removes these objects and loses post-upgrade owner
  values.
- Security/ownership/tenant: Owner filters run in SQL before response material
  is returned; cross-owner and missing probes are equivalent; bulk writes are
  set-based/all-or-nothing; background work rechecks authorization; retained
  records and role transitions are serialized with database locks.
- Dependency/toolchain: No dependency was added. Playwright uses the existing
  Node/Next toolchain with isolated ports and caches.
